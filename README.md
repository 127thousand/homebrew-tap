# 127 Thousand's Homebrew tap

```
brew install --cask 127thousand/tap/hackmarket
```

| Cask | App |
|---|---|
| `hackmarket` | [HackMarket](https://hackmarket.dev): simulated trading for the dev stack, for macOS 12 or later. The notarized Developer ID build from https://download.hackmarket.dev; the same app is on the Mac App Store. |

The cask is updated by HackMarket's release workflow on every Mac release.
